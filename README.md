# Эти дни

Календарь менструального цикла для Android. Вход, анкета и прогноз живут только на телефоне: сервер и ключи API не нужны.

Интерфейс на русском. Это не медицинское изделие и не средство контрацепции — даты в приложении всегда подписаны как оценка.

## Что умеет

- Локальная регистрация и вход. Пароль хранится как PBKDF2-хеш с солью, не как текст. Сессия остаётся, пока пользователь сам не выйдет.
- Анкета: дата рождения, вес, рост, первый день последней менструации. Длину цикла и менструации можно задать самой. Если длину цикла не указать, приложение берёт спокойную оценку по возрасту и ИМТ и прямо пишет об этом. По умолчанию менструация — 5 дней.
- Прогноз: следующее окно менструации, овуляция (за 14 дней до следующей менструации), фертильное окно, настроение (ПМС и короткая заметка около овуляции), кожа. Возраст и ИМТ не добавляют «точность»: они только снижают уверенность, если цикл чаще бывает неровным (до 18 лет, после 45, ИМТ ниже 18,5 или от 30).
- Месяц с отметками, легендой и сегодняшним днём. Между месяцами можно листать.
- Напоминания за день и в день события, около 9:00 по местному времени. Каждый тип можно выключить. Очередь — WorkManager; система может немного сдвинуть доставку. На Android 13+ запрашивается разрешение на уведомления. После правки анкеты очередь пересчитывается.
- Запись в календарь телефона через `CalendarContract`: менструация, овуляция, настроение, кожа. Если на устройстве есть аккаунт Google, его календарь обычно виден здесь же. Отдельный серверный клиент Google Calendar API не нужен. Свои события помечены фразой `[Эти дни]`, пакетом приложения и служебным свойством, поэтому удаляются только они. Старые события с меткой `[lovelyDays]` тоже удаляются. Нет календаря — остальное приложение всё равно работает.

## Как открыть в Android Studio

1. Поставьте Android Studio с Android SDK 35 (и JDK 17 или новее).
2. **File → Open** и выберите папку этого проекта.
3. Дождитесь синхронизации Gradle. Если SDK не находится, Studio создаст `local.properties` со строкой `sdk.dir`. Этот файл в git не входит.
4. Запустите конфигурацию `app` на эмуляторе или телефоне с Android 8.0 (API 26) или новее.

## Сборка из терминала

Нужны JDK 17+ и Android SDK 35. Путь к SDK — в `ANDROID_HOME` (или в `local.properties`, его создаёт Android Studio):

```bash
export ANDROID_HOME="$HOME/Android/Sdk"
./gradlew assembleDebug
```

Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`.

Проверка расчётов без устройства:

```bash
./gradlew testDebugUnitTest
```

`assembleDebug` проверяет, что проект собирается. Это не запуск на телефоне и не проверка уведомлений или календаря на живом устройстве.

## Стек

Kotlin, Jetpack Compose, Material 3, Gradle Kotlin DSL, version catalog, Room, DataStore, WorkManager. `minSdk` 26. На телефоне приложение называется «Эти дни»; идентификатор пакета `com.lovelydays` не менялся. Иконка — адаптивная, только полумесяц.
